# Sváteční oběd U Rozvařilů

Jednoduchá stránka s odpočtem do 27. října 2026 v 11:30.

## Zveřejnění přes GitHub Pages

1. Na GitHubu vytvoř nový veřejný repository, například `svatecni-obed-u-rozvarilu`.
2. Nahraj do něj soubory:
   - `index.html`
   - `jidlo_a_kava.png`
3. V repository otevři **Settings → Pages**.
4. U **Build and deployment** vyber **Deploy from a branch**.
5. Vyber větev `main` a složku `/ (root)`.
6. Klikni na **Save**.
7. Po chvíli GitHub zobrazí adresu zveřejněné stránky.

Stránka nevyžaduje žádný server ani instalaci. Odpočet se počítá přímo v prohlížeči.
